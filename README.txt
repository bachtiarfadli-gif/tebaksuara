MEDIA PEMBELAJARAN PAUD - AYO TEBAK SUARA!

CARA MENJALANKAN SECARA LOKAL
1. Ekstrak seluruh isi ZIP ke satu folder.
2. Pastikan susunan folder tetap seperti ini:
   - index.html
   - level2.html
   - level3.html
   - README.txt
   - assets/style.css
   - assets/data.js
   - assets/match.js
   - assets/imitation.js
3. Buka index.html menggunakan Google Chrome, Edge, atau browser modern.
4. Koneksi internet diperlukan karena audio dimuat dari Wikimedia Commons.

CARA MEMPERBARUI GITHUB PAGES
1. Buka repository GitHub yang digunakan untuk website.
2. Upload seluruh file dan folder dari paket ini ke root repository.
3. Pilih untuk mengganti file lama jika diminta, terutama index.html.
4. Pastikan folder assets ikut terunggah, jangan hanya index.html.
5. Commit changes. Jika GitHub Pages sudah aktif pada branch main dan folder /(root), website akan diperbarui otomatis.
6. Buka kembali alamat website. Jika tampilan lama masih tersimpan, lakukan hard refresh (Ctrl + Shift + R).

ALUR PEMBELAJARAN
Tahap 1 - index.html
Anak mendengarkan suara ayam, hujan, dan kucing, kemudian mencocokkan setiap tombol suara dengan gambar yang sesuai.

Tahap 2 - level2.html
Setelah semua jawaban benar, tombol Lanjut membuka halaman baru berisi suara sapi, lonceng sekolah, dan petir.

Tahap 3 - level3.html
Konsep dibalik: gambar ditampilkan terlebih dahulu, anak mendengar contoh suara, lalu menirukannya. Anak menekan tombol "Aku sudah menirukan" setelah mencoba. Guru mengamati dan memberi penilaian secara langsung.

CATATAN PENTING
- Website tidak menggunakan login, database, backend, atau halaman admin.
- Website tidak merekam suara anak dan tidak menilai ketepatan tiruan secara otomatis. Penilaian tahap ketiga dilakukan guru secara langsung.
- Audio menggunakan URL Wikimedia Commons, sehingga koneksi internet diperlukan agar audio dapat diputar.
- Drag-and-drop mendukung mouse dan layar sentuh. Anak juga dapat mengetuk tombol suara, kemudian mengetuk kotak gambar sebagai alternatif.
